\# Tic-Tac-Toe Game (Java Swing GUI)



A lightweight, desktop-based Tic-Tac-Toe game featuring a dual-player scoreboard, custom UI components, and real-time state resets. This project was developed utilizing Java Swing and Abstract Window Toolkit (AWT).



\## 🚀 Features

\* \*\*Two-Player Local Gameplay:\*\* Turn-based mechanics seamlessly alternating between Player 1 (O) and Player 2 (X).

\* \*\*Persistent Scoreboard:\*\* Automatically tracks and displays cumulative match wins during active sessions.

\* \*\*Smart Board Resets:\*\* Dedicated reset utility clearing states, button text, and UI interactions without losing the session's scoreboard data.

\* \*\*Modal Confirmations:\*\* Native dialog boxes to confirm application exits and announce match ties or match wins.



\## 🛠️ Built With

\* \*\*Language:\*\* Java (JDK 8 or higher)

\* \*\*GUI Framework:\*\* Java Swing \& AWT (Abstract Window Toolkit)

\* \*\*Original IDE Layout:\*\* Apache NetBeans GUI Builder

\## 💻 How to Run



\### Method 1: Via the Command Line

Ensure you have the Java Development Kit (JDK) installed and configured in your environment paths.



1\. Open your terminal/command prompt and navigate to the project source directory:

&#x20;  ```bash

&#x20;  cd Tic-Tac-Toe-game\_Java/src


2. Compile the Java file:



&#x20;  ```bash

&#x20;javac TIC\_TAC.java



3\. Run the application:



&#x20;  ```bash

&#x20;java TIC\_TAC



\### Method 2: Via an Integrated Development Environment (IDE)



Because this project utilizes a native NetBeans directory structure (nbproject/), opening it in an IDE is seamless:



Apache NetBeans: Go to File > Open Project > select the Tic-Tac-Toe-game\_Java root folder. Click the green Run Project button.



IntelliJ IDEA / Eclipse: Choose Import Project or Open, point it to the root directory, configure the project SDK (Java v8+), and execute the main method located within TIC\_TAC.java.
